# Вехи

Командные дорожные карты на бесконечном холсте. Этапы с подзадачами, связи между ними, рисование поверх карты, совместная работа в реальном времени, CLI и HTTP API для генерации карт из документов.

## Что умеет

- **Карты и этапы.** Боковая панель со списком карт и этапов, фильтры «Все / Активные / Готовые», поиск по картам, этапам и подзадачам.
- **Карточки этапов.** Метка (владелец, «параллельно» или любая своя), статус, описание, вложенные подзадачи с прогрессом, срок и приоритет. Статус сам переходит в «В работе» и «Готово» по мере отметки подзадач.
- **Связи.** Потяните за точку на краю карточки к другой карточке. Сплошная линия значит «последовательно», пунктир значит «параллельно», у связи может быть подпись.
- **Рисование.** Прямоугольник, ромб, эллипс, стрелка, карандаш, текст, картинка (также вставка из буфера и перетаскивание файла), ластик.
- **Навигация.** Колёсико прокручивает, Ctrl + колёсико или щипок масштабирует, пробел + мышь двигает холст, миникарта, «показать всё» (Shift+1).
- **Команда.** Вход по email и паролю, приглашения по одноразовой ссылке, роли «Администратор», «Участник», «Только просмотр». Курсоры и аватары коллег видны в реальном времени.
- **Экспорт и импорт.** JSON, Markdown, PNG. Импорт JSON с автоматической расстановкой этапов по связям.

Горячие клавиши: `1` выбор, `2` прямоугольник, `3` ромб, `4` эллипс, `5` стрелка, `6` карандаш, `7` текст, `8` картинка, `9` ластик, `0` новый этап, `H` рука, `Ctrl+Z` / `Ctrl+Shift+Z` отмена и повтор, `Delete` удалить выделенное. В подзадаче `Enter` создаёт следующую, `Tab` и `Shift+Tab` меняют вложенность.

## Запуск локально

Нужен Node.js 22.5 или новее (используется встроенный SQLite, ничего компилировать не надо).

```bash
npm install
npm start          # http://localhost:3000
```

Первый зарегистрированный пользователь становится администратором. Остальные заходят по приглашению: «Настройки → Команда → Создать приглашение».

Данные лежат в папке `data/` (база `roadmap.db` и загруженные картинки). Для резервной копии достаточно копировать эту папку.

## Развёртывание на сервере

Подойдёт любой VPS с Docker (Hetzner, Timeweb, Selectel, DigitalOcean и т. п.), 1 ГБ памяти хватает.

```bash
git clone <репозиторий> roadmap && cd roadmap
docker compose up -d --build
```

Приложение поднимется на порту 3000. Для HTTPS проще всего поставить перед ним [Caddy](https://caddyserver.com), он сам получит сертификат:

```
# /etc/caddy/Caddyfile
roadmap.example.com {
    reverse_proxy localhost:3000
}
```

После включения HTTPS поставьте `COOKIE_SECURE: "1"` в `docker-compose.yml` и выполните `docker compose up -d`.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт HTTP |
| `DATA_DIR` | `./data` (в Docker `/data`) | где хранить базу и картинки |
| `COOKIE_SECURE` | `0` | `1`, чтобы cookie входа отправлялась только по HTTPS |
| `TRUST_PROXY` | `1` | `0`, если приложение смотрит в интернет без прокси |

## CLI и API

Создайте токен в «Настройки → CLI и API».

```bash
export ROADMAP_URL=https://roadmap.example.com
export ROADMAP_TOKEN=rm_...

node cli/roadmap.js list
node cli/roadmap.js import examples/game-release.json
node cli/roadmap.js export <id> --md -o plan.md
node cli/roadmap.js format      # пример формата
```

Так можно попросить Claude Code или любой другой скрипт собрать дорожную карту из дизайн-документов: пусть он сохранит JSON в формате ниже и выполнит `roadmap import`.

```json
{
  "name": "Релиз 1.0",
  "stages": [
    { "id": "m0", "lane": "Владелец", "title": "Аккаунт и ранние шаги",
      "desc": "Что нужно сделать в первую неделю",
      "status": "active", "due": "2026-11-20", "priority": "high",
      "subtasks": ["Завести аккаунт", { "t": "Проверить доступы", "done": true, "c": ["Сервер", "Репозиторий"] }] },
    { "id": "m1", "lane": "Параллельно", "title": "Лицензии и ассеты" }
  ],
  "links": [{ "from": "m0", "to": "m1", "style": "dashed", "label": "параллельно" }]
}
```

- `status`: `planned`, `active` или `done`.
- `priority`: `low`, `medium` или `high`.
- Подзадача: строка или объект `{ "t": текст, "done": bool, "c": [вложенные] }`.
- `x` и `y` у этапов не обязательны: без них этапы расставятся колонками по связям.

HTTP API (заголовок `Authorization: Bearer rm_...`):

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/api/maps` | список карт с прогрессом |
| `POST` | `/api/maps/import` | создать карту из JSON выше |
| `GET` | `/api/maps/:id` | карта со всеми этапами, связями и рисунками |
| `GET` | `/api/maps/:id/export` | JSON в формате импорта, `?format=md` для Markdown |
| `POST` | `/api/maps/:id/ops` | пакет изменений `{ ops: [{ kind: "node"\|"edge"\|"shape", id, data\|null }] }` |
| `PATCH` | `/api/maps/:id` | переименовать `{ name }` |
| `DELETE` | `/api/maps/:id` | удалить карту |

## Устройство

- `server/index.js` — HTTP, вход, API, WebSocket для живых обновлений и курсоров.
- `server/model.js` — формат данных, импорт с авторасстановкой, экспорт в JSON и Markdown.
- `server/db.js` — SQLite (встроенный модуль Node).
- `public/` — интерфейс без сборки: `index.html`, `app.css`, `app.js`.
- `cli/roadmap.js` — командная строка.
