# Запуск Вех на Hetzner

Около 15 минут и примерно €6 в месяц (сервер CX23 за €5.49 плюс €0.50 за IPv4). Деньги списываются по часам, сервер можно удалить в любой момент.

## 1. SSH-ключ на вашем компьютере

Ключ нужен, чтобы заходить на сервер без пароля. В PowerShell (Windows) или терминале (macOS, Linux):

```bash
ssh-keygen -t ed25519
```

На все вопросы нажимайте Enter. Потом покажите публичную часть ключа и скопируйте её целиком (строка начинается с `ssh-ed25519`):

```bash
# Windows PowerShell
type $env:USERPROFILE\.ssh\id_ed25519.pub
# macOS / Linux
cat ~/.ssh/id_ed25519.pub
```

## 2. Создание сервера

1. В [console.hetzner.com](https://console.hetzner.com/projects) откройте проект (или создайте новый, например `vehi`).
2. Нажмите **Create Resource → Servers** (или **Add Server**).
3. **Location**: Falkenstein или Nuremberg (Германия). Из Украины это самый быстрый вариант.
4. **Image**: Ubuntu 24.04.
5. **Type**: Shared vCPU → x86 → **CX23** (2 vCPU, 4 GB). Если его нет в выбранной локации, возьмите ARM **CAX11** или смените локацию на Helsinki.
6. **Networking**: оставьте галочку **Public IPv4**.
7. **SSH keys → Add SSH key**: вставьте строку из шага 1.
8. Остальное не трогайте. Name: `vehi`. Нажмите **Create & Buy now**.
9. Через полминуты появится IP-адрес сервера. Скопируйте его.

Порты у Hetzner по умолчанию открыты, отдельно настраивать файрвол не нужно.

## 3. Бесплатный адрес

1. Зайдите на [duckdns.org](https://www.duckdns.org) через Google или GitHub.
2. Придумайте поддомен, например `vehi-team`, и нажмите **add domain**.
3. В поле **current ip** вставьте IP сервера и нажмите **update ip**.

Если у вас есть свой домен, вместо этого создайте у регистратора A-запись на IP сервера.

## 4. Установка

```bash
ssh root@IP_СЕРВЕРА
```

На вопрос про fingerprint ответьте `yes`. На сервере выполните одну команду, подставив свой адрес:

```bash
curl -fsSL https://raw.githubusercontent.com/dontpani6/roadmap/main/deploy/install.sh | bash -s -- vehi-team.duckdns.org
```

Через 2–3 минуты скрипт напишет «Готово».

## 5. Первый вход

1. Откройте `https://vehi-team.duckdns.org` и зарегистрируйтесь. Первый пользователь становится администратором.
2. **Настройки → Команда → Создать приглашение** и отправьте ссылки коллегам.
3. **Настройки → ИИ и API → Создать токен**, затем «Копировать URL для Claude» и добавьте его в Claude: Настройки → Коннекторы → Добавить свой коннектор.

Обновления ставятся сами каждые 5 минут, резервная копия данных делается каждую ночь в `/opt/roadmap/backups`. Для дополнительной страховки в Hetzner можно включить Backups у сервера (+20% к цене).
